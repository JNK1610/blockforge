Hinweise

Ein Block entspricht einem Minecraft-Block. Die exportierte .schem-Datei enthält die gewählten Blockzustände einschließlich Treppenausrichtung. Die Datei sollte vor dem Einsatz auf dem Server in einer Testwelt überprüft werden. JSON ist für das spätere Weiterbearbeiten im Browser gedacht.
