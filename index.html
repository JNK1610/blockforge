Projekt

Originalgetreue Blockpositionen und Blockzustände aus der hochgeladenen .litematic. Die 3D-Ansicht verwendet vereinfachte Geometrie für Sonderblöcke.

Werkzeuge

Im 3D-Modus: auf einen Block klicken, um an dessen Seite anzubauen. Mit Entfernen einen Block abbauen. Im 2D-Modus direkt zeichnen.

Hinweise

Ein Block entspricht einem Minecraft-Block. Die Originaldatei .litematic bleibt unverändert. Der zusätzliche .schem-Export wird aus den importierten Blöcken neu erzeugt. Die Datei sollte vor dem Einsatz auf dem Server in einer Testwelt überprüft werden. JSON ist für das spätere Weiterbearbeiten im Browser gedacht.
